# Titanic Survival Prediction Using Machine Learning

## Overview

This project uses Machine Learning to predict whether a passenger survived the Titanic disaster based on passenger information such as age, gender, class, fare, and embarkation point.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab

## Machine Learning Algorithm

* Random Forest Classifier

## Project Workflow

1. Data Loading
2. Data Cleaning and Preprocessing
3. Feature Selection
4. Train-Test Split
5. Model Training
6. Prediction
7. Model Evaluation
8. Visualization

## Results

* Accuracy: 82.12%
* Confusion Matrix generated
* Feature Importance visualization generated

## Key Insights

The most important features influencing survival prediction were:

* Sex
* Fare
* Age
* Passenger Class (Pclass)

## Outcome

Successfully built and evaluated a supervised Machine Learning model for Titanic survival prediction.
